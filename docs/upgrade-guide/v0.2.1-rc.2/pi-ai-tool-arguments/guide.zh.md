# PI-AI 拒绝格式错误的工具参数

[English](guide.md) | 中文

## 变更

PI-AI 1.4.0 会标记无法将参数解析为 JSON 对象的完整工具调用。DSH 的 PI-AI 适配器在执行该响应中的任何工具之前报告 `INVALID_REQUEST`，不会替换为空参数对象，也不会执行同一响应中较早出现的有效工具调用。

因输出限制停止的响应保留既有 `max-tokens` 处理方式。此变更不会迁移已保存的对话，也不改变工具 schema。

## 迁移

1. 如果 PI-AI 响应因工具参数错误而报告 `INVALID_REQUEST`，请将生成的参数修正为完整 JSON 对象，再重试该轮。自定义重试处理器不得将格式错误的参数视为 `{}`。
2. 消费流式输出的集成必须等到终态结果后再分派工具。单独的工具调用结束事件不代表整个响应成功。
3. 确认格式错误、并非因输出限制而截断、以及不是对象的工具参数会产生错误且没有工具副作用。有效参数和因输出限制停止的响应保留正常处理方式。
